How this works · Contribute

This little community project brings together a forecast and recent radar observations to give you some context before playing. It is independent of the club, and it cannot tell you whether a court is safe. Always check conditions where you are.

Where the report comes from

MET Norway supplies the forecast for Royal Lake Club’s location. RainViewer supplies up to six recent historical radar images, checked for nearby rain echoes. Radar shows what has been observed; it is not a prediction of where rain will go. IQAir air-quality readings are currently disabled until access and public-display permissions are confirmed.

For the curious

  • Plain JavaScript runs on Node 22 or newer. One scheduled writer refreshes an atomic JSON snapshot; the page reads it through a read-only API. There is no public refresh endpoint.
  • The report refreshes every ten minutes, and an open page checks it once a minute. Provider data can update less often: MET’s expiry and conditional-request rules are respected, and radar metadata is checked at most every ten minutes.
  • Each API read checks freshness again. A report older than twenty minutes suppresses current risk guidance. Forecasts older than twelve hours and radar observations older than thirty minutes cannot provide current guidance; missing or invalid data is shown as unavailable.
  • The rain-risk score combines forecast information and recent radar observations using a simple heuristic. It is not a calibrated probability, storm-tracking model or safety assessment. Coverage and provider failures can leave the report incomplete.

Help make it better

Have a better way to understand weather around the club? Developers are welcome to explore the MIT-licensed source on GitHub, share an issue or idea, or submit a pull request. Improvements to data coverage, clarity and reliability are especially welcome. The repository explains the calculations, tests and providers’ separate data terms.
